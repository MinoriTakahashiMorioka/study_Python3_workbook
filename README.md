# Py3 基礎試験ドリル

**Python3エンジニア認定基礎試験**の対策用、ブラウザで動く学習アプリです。
勉強ゼロからでも「単語 → 写経 → 穴埋め → 読解 → お題」の順に進めれば、試験範囲（オライリー『Pythonチュートリアル』）の重要ポイントを手を動かしながら覚えられます。

| モード | 内容 | 収録数 |
|---|---|---|
| 単語帳 | 用語・関数の意味をカード／4択（用語→意味・意味→用語）で覚える | 150語以上 |
| 写経 | お手本コードを1文字ずつ打ち込む。ミスは赤く表示、タイム記録あり | 17本 |
| 穴埋め | コードの空欄を埋める。正解後に完成コードを実行できる | 19問 |
| コード読解 | 「出力は？」「何をしている？」本番形式の4択。実行して確かめられる | 61問 |
| お題（Paiza風） | 入力を読んで正しい出力が出せればAC。隠しテストあり | 16問 |

- Python はブラウザ内（[Pyodide](https://pyodide.org/)）で実行されるので、**Python のインストールは不要**
- 無限ループしても5秒で止まる（TLE表示）
- 学習記録はブラウザに自動保存。エクスポート／インポートも可能
- 右上のボタンでダーク／ライトを切り替え（最初はOSの設定に合わせる）
- サーバー不要の素の HTML / CSS / JavaScript。ビルドもなし

> 試験概要（目安）：40問・60分・正答率70%で合格・選択式（CBT）。最新の情報は必ず公式サイトで確認してください。

## 1. VSCode で開いて動かす

1. このフォルダを VSCode で開く（`ファイル > フォルダーを開く`）
2. 右下に出る「推奨拡張機能をインストール」から **Live Server** を入れる
   （出ない場合は拡張機能で `ritwickdey.LiveServer` を検索）
3. `index.html` を右クリック → **Open with Live Server**
4. ブラウザが開いたら完成！

`index.html` をダブルクリックで直接開いても動きますが、ブラウザによっては Python 実行がブロックされるので Live Server 推奨です。
初回の Python 実行時だけ、実行エンジン（約10MB）の読み込みに数秒〜十数秒かかります。インターネット接続が必要です。

## 3. 問題を追加・編集する

問題はすべて `data/` フォルダの JS ファイルに入っています。**同じ形のオブジェクトを配列に足すだけ**で画面に反映されます。

```
data/
├─ vocab.js      単語帳
├─ typing.js     写経
├─ fill.js       穴埋め
├─ reading.js    コード読解
└─ problems.js   お題
```

### コードは `String.raw` で書く

```js
code: String.raw`print('a\nb')`,   // \n がそのまま Python に渡る
```

ふつうの `` `...` `` だと `\n` が JavaScript 側で改行に変わってしまうので注意。

### 例：穴埋めを1問追加

```js
{
  id: 'f20', cat: 'ch5', title: 'タプルのアンパック',
  goal: '出力: 1 2',
  code: String.raw`t = (1, 2)
{{x}}, y = t
print(x, y)`,
  explain: 'タプルの要素を複数の変数に一度に代入できる。',
},
```

- `{{答え}}` が空欄になる。別解は `{{答え1||答え2}}`
- 採点は空白を無視し、`'` と `"` を同じ扱いにします

### 例：お題を1問追加

```js
{
  id: 'p17', level: 'D', cat: 'ch3', title: '2倍にする',
  statement: '整数 n が与えられるので 2n を出力してください。',
  input: 'n', output: '2n の値',
  tests: [
    { in: '3', out: '6', sample: true },   // sample:true は問題文に表示
    { in: '-5', out: '-10' },              // それ以外は提出時だけの隠しテスト
  ],
  template: 'n = int(input())\n',
  hint: '掛け算は * です。',
  answer: String.raw`n = int(input())
print(n * 2)`,
},
```

### カテゴリ（章）の一覧

`cat` には次のキーを使います（`js/ui.js` の `U.CATS` で定義）。

| キー | 章 |
|---|---|
| ch1 | 1〜2章 はじめに・インタープリタ |
| ch3 | 3章 気楽な入門編 |
| ch4 | 4章 制御構造・関数 |
| ch5 | 5章 データ構造 |
| ch6 | 6章 モジュール |
| ch7 | 7章 入出力 |
| ch8 | 8章 エラーと例外 |
| ch9 | 9章 クラス |
| ch10 | 10〜11章 標準ライブラリ |
| ch12 | 12章〜 仮想環境・浮動小数点 |

### メモ

- 写経のコードには日本語を入れないのがおすすめ（日本語入力の変換中に判定がずれるため）
- 読解の `answer` は **0始まり**の番号（選択肢は画面でシャッフルされます）

## 4. 問題集ページ（公式問題集・個人学習用）

ナビの「問題集」から、公式問題集の全138問（第1〜12章 98問＋総仕上げ問題40問）を解けます。

- **章ごとに解く**：本の順番で1問ずつ。答えるとすぐ正誤と、解説ページの写真が見られます
- **コードの問題は実行できる**：空欄問題は「自分の答え」「正解」をそれぞれ空欄に入れて実行して比べられます
- **間違えた問題だけ** / **ランダム20問**
- **総仕上げ模試**：40問・60分タイマー・見直し印つき。最後にまとめて採点し、記録が残ります
- **選択肢をシャッフル**：ONにすると選択肢の並び（A〜E）が毎回ランダムに。記号の位置で答えを覚えるのを防げます。正解表示には「本では B」のように本での記号も出ます（設定は保存されます）

データは `official/` フォルダ（`workbook.js` と解答ページの写真 `answers/`）にあります。
**著作物なので `.gitignore` で GitHub に上がらないようにしてあります。**
別のPCで使うときは `official` フォルダごとコピーしてください。

```

├─ index.html          画面の土台
├─ css/style.css       見た目（ダーク／ライトの色は :root の変数で一括変更可）
├─ js/

│  ├─ app.js           画面切り替え（#/vocab などのURLで切り替え）
│  ├─ store.js         学習記録の保存（localStorage）
│  ├─ ui.js            共通部品・簡易コードエディタ
│  ├─ runner.js        ブラウザ内Python実行（Pyodide + Web Worker）
│  └─ modes/           各モードの画面
└─ data/               問題データ
```

## 6. エディタのショートカット

| キー | 動作 |
|---|---|
| Tab / Shift+Tab | 4スペースのインデント / 解除（複数行選択も可） |
| Enter | 前の行のインデントを引き継ぐ（`:` で終わる行のあとは +4） |
| Backspace | 行頭の空白を4つずつ消す |
| Ctrl(⌘) + Enter | お題：入力例で実行 |
| 1〜4 / A〜D | 単語帳・4択：選択肢を選ぶ |
